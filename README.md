# Omarchy Ethiopia Retro Theme

A vintage theme for Omarchy Linux inspired by 1960s Addis Ababa culture, literature, and urban heritage.

## Installation

### Option 1: Via the Omarchy Menu (Recommended)
1. Copy this repository URL: `[https://github.com/Abemelek97/ethiopia-retro-themes](https://github.com/Abemelek97/ethiopia-retro-themes)`
2. Press `Super + Alt + Space` to open the Omarchy menu.
3. Select **Install → Style → Theme** and paste the URL.

---

### Option 2: Manual Clone
Clone into your local Omarchy themes directory:

```bash
git clone https://github.com/Abemelek97/ethiopia-retro-themes.git ~/.config/omarchy/themes/ethiopia-retro
